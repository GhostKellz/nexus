**New Capabilities**:
- **Stream Priority**
  - Dependency trees with exclusive dependencies
  - Weight-based scheduling (1-256)

  - Priority frame sending/receiving

- **Flow Control**
  - Connection-level window management
  - Stream-level window management
  - Automatic WINDOW_UPDATE sending
  - Configurable initial window size

- **Frame Processing**
  - `processFrame()` - Central frame dispatcher
  - `handleDataFrame()` - DATA frame with flow control
  - `handleHeadersFrame()` - HEADERS with priority extraction
  - `handlePriorityFrame()` - PRIORITY frame processing
  - `handleRstStreamFrame()` - RST_STREAM handling
  - `handleSettingsFrame()` - SETTINGS negotiation
  - `handlePingFrame()` - PING/PONG for keepalive
  - `handleGoAwayFrame()` - Graceful shutdown
  - `handleWindowUpdateFrame()` - Flow control updates

- **Multiplexing**
  - Concurrent stream management (up to 100 streams)
  - Stream state machine (idle → open → half_closed → closed)
  - `runEventLoop()` - Async frame processing
  - `getStreamsByPriority()` - Priority-ordered stream scheduling

**Impact**: High-performance HTTP/2 for gRPC and modern web applications.

### Generate TLS Certificate with Let's Encrypt
```zig
const acme = @import("stdlib/net/acme.zig");

var client = try acme.Client.init(allocator, acme.AcmeDirectory.LETS_ENCRYPT_PROD);
defer client.deinit();

try client.createAccount("admin@example.com", true);
const domains = [_][]const u8{"example.com"};
const cert = try client.requestCertificate(&domains);
```
